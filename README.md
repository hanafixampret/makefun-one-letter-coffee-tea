One letter, A for coffee or B for tea. `main.ts` writes it to `<output>/entry.txt` so the AI judge can compare it head to head against the other entries.

The letter: **A** — coffee. The more vivid, funnier and truer answer: the fuel agents actually run on.

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset).
